# PixelPantry 🍳

A personal digital cookbook. Recipes are stored as data and rendered
into cards by a Python script, hosted live on AWS S3.

**Live site:** http://pixelpantry-foled.s3-website.us-east-2.amazonaws.com

## Tech stack

- HTML/CSS
- Python (generates recipe cards from JSON)
- Vanilla JavaScript (random recipe button)
- AWS S3 static website hosting
- Git/GitHub
